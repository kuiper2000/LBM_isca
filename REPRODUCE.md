# Reproducing the PyLBM-Isca v1.0.0 results

This document lists the exact commands, inputs, and seeds needed to reproduce the
principal results of the GMD manuscript from a clean checkout. All commands are
run from the repository root.

## Release identity

- Code: tag **v1.0.0**, GitHub `kuiper2000/PyLBM-Isca`, Zenodo version DOI
  **10.5281/zenodo.24114461** (concept DOI 10.5281/zenodo.24084237).
- Input data: Zenodo **10.5281/zenodo.24086134**.

## 1. Environment

```bash
python -m venv venv && . venv/bin/activate      # Python >= 3.9
pip install -r requirements.txt                 # NumPy + SciPy (+ optional extras)
# GPU (optional): pip install cupy-cuda12x       # match your CUDA toolkit
```

The paper's timings used NumPy 2.4 (MKL), CuPy 14.2 (CUDA 12.9), gfortran 11.5;
results are backend-independent to float64 round-off (Sect. 5.5), so any recent
NumPy/CuPy reproduces the scientific figures.

## 2. Input data

The idealised experiments (Gill, solid body) build their basic states
analytically and need no files. The realistic and summer experiments read binary
inputs archived on Zenodo (not in git; `*.bin` is `.gitignore`d):

```bash
mkdir -p data && cd data
curl -LO "https://zenodo.org/records/24086134/files/bs.1979.bin?download=1"   # DJF 1979 basic state
curl -LO "https://zenodo.org/records/24086134/files/frc.phase1.bin?download=1" # MJO phase-1 heating
# bs.jja.bin (summer basic state) is archived alongside these; see data/README.md
cd ..
```

## 3. Verification suite (fast, CPU, deterministic)

```bash
python tests/test_spectral.py            # spherical-harmonic transforms
python tests/test_vertical_isca.py       # Simmons-Burridge operators
python tests/test_vert_advection_sign.py # vertical-advection sign invariant
python tests/test_physics_isca.py        # zero-state, Gill response, conditioning
python tests/test_tangent_linear.py      # tangent-linear operator (item 3)
```

## 4. Principal experiments and figures

| Result (manuscript) | Command | Seed / key settings |
|---|---|---|
| Gill, solid-body, realistic MJO figures | `python analysis/make_figures_isca.py` | T42L20, dt=1200 s, days 15–30 |
| Realistic MJO run (GrADS/netCDF output) | `python run_lbm.py --basic-state data/bs.1979.bin --mjo-forcing data/frc.phase1.bin --days 35 --out out/isca.1979.phase1 --device auto` | — |
| Tangent-linear verification (Fig., item 3) | `python analysis/tl_verification.py` | perturbation seed **0** |
| Instability & averaging window (item 4) | `python analysis/stability_diagnostics.py` | init seed **1**, dt∈{1200,600,300} |
| Summer (JJA) validation (item 5) | `python analysis/summer_validation.py` | days 15–30, 200 hPa; JJA capped above 100 hPa |
| Resolution scaling (perf) | `python analysis/benchmark_perf_isca.py` | T21–T106, warmed-up, device-synced |
| Ensemble throughput | `python analysis/benchmark_ensemble_isca.py` | E = 1…512 |
| Fully-utilized CPU-node baseline | `python analysis/benchmark_ensemble_isca.py --cpu-procs 32` | 32 concurrent single-thread processes |
| Forcing-uncertainty ensemble | `python analysis/a9_ensemble_uncertainty_isca.py` | N=50, 10% amp + ±5° shift |
| CPU↔GPU parity (Table 6 / §5.5) | `python analysis/compare_runs.py <cpu>.grd <gpu>.grd` | records in `analysis/*_cpu_gpu_parity.json` |

Diagnostic scripts write their figures and a JSON record next to the script
(`analysis/*.pdf`, `analysis/*.json`); the generated PDFs/PNGs are `.gitignore`d
and regenerated by re-running the script.

## 5. Notebooks (browser / Colab)

`examples/example_1_gill.ipynb`, `example_2_solidbody.ipynb`, and
`example_3_realistic.ipynb` reproduce the three verification experiments;
example 3 downloads the inputs from Zenodo on first run. They also run on the
free Google Colab GPU runtime (badge in `README.md`).

## 6. Notes on agreement figures

The automated parity tolerances in `tests/` are loose pass/fail guards (e.g.
`1e-6` relative for a full integration); the **observed** CPU–GPU differences are
~`1e-10` and are recorded in `analysis/sb_cpu_gpu_parity.json` and
`analysis/mjo_cpu_gpu_parity.json` (manuscript §5.5).
